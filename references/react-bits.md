# React Bits 组件收藏

从 React Bits 收藏的 21 个候选组件。每项名称都链接到官方演示，适合在确定页面结构后，用来挑选局部动效、导航或表单控件。 [React Bits 官方目录](https://www.reactbits.dev/get-started/index)

## 背景 · Backgrounds

- [Galaxy](https://www.reactbits.dev/backgrounds/galaxy) · 星系粒子背景，适合有明确主题的封面或展示区。

## 动画 · Animations

- [GradualBlur](https://www.reactbits.dev/animations/gradual-blur) · 给滚动区或图片轮播的边缘做渐进模糊。
- [OrbitImages](https://www.reactbits.dev/animations/orbit-images) · 让一组图片沿轨道运动，适合视觉展示。
- [AnimatedContent](https://www.reactbits.dev/animations/animated-content) · 内容进入视口时做轻量的入场过渡。
- [Strands](https://www.reactbits.dev/animations/strands) · 丝束光效，适合需要独立视觉焦点的展示区。
- [Magnet](https://www.reactbits.dev/animations/magnet) · 元素随指针靠近产生吸附感，适合支持悬停的场景。

## 组件 · Components

- [HoloCard](https://www.reactbits.dev/components/holo-card) · 带全息反光的展示卡，适合收藏品或展品。
- [AccordionGallery](https://www.reactbits.dev/components/accordion-gallery) · 展开一张图的同时收起其他图，适合图片导览。
- [ReflectiveCard](https://www.reactbits.dev/components/reflective-card) · 用动态反光表现材质，适合突出展示单张卡片。
- [CardNav](https://www.reactbits.dev/components/card-nav) · 把一组导航链接展开为多张分组卡片。
- [GlassSurface](https://www.reactbits.dev/components/glass-surface) · 给浮层或工具条增加半透明玻璃质感。
- [Folder](https://www.reactbits.dev/components/folder) · 用可开合的文件夹呈现一组内容。
- [ModelViewer](https://www.reactbits.dev/components/model-viewer) · 用于需要旋转查看的 3D 模型展示。
- [Dock](https://www.reactbits.dev/components/dock) · 适合常用工具或快捷入口集中的工具栏。
- [GooeyNav](https://www.reactbits.dev/components/gooey-nav) · 为导航切换增加流体过渡。
- [PixelCard](https://www.reactbits.dev/components/pixel-card) · 像素反馈卡片，适合像素风或游戏主题。
- [SpotlightCard](https://www.reactbits.dev/components/spotlight-card) · 用局部光斑突出指针所在的卡片。
- [Stepper](https://www.reactbits.dev/components/stepper) · 用于步骤明确的分步表单或引导流程。

## 微交互 · Micro

- [GlideSelect](https://www.reactbits.dev/micro/glide-select) · 用于短选项列表，比如周期或筛选项。
- [LatticeLoader](https://www.reactbits.dev/micro/lattice-loader) · 用于需要显示等待过程或已耗时的任务状态。
- [BellToggle](https://www.reactbits.dev/micro/bell-toggle) · 用于提醒开关，让状态变化有明确反馈。

## 使用时检查

移动端优先检查实际触控、键盘弹出和减弱动态效果。依赖悬停的交互要有触控入口，全屏背景、3D 和高开销动效适合在目标设备上先预览。
