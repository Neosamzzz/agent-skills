# 工程式素材与配方编辑器

把对象关系、输入动作和状态变化设计清楚，再做界面。这里提供经过实际编辑器使用验证的基线；具体布局、按键和入口以当前用户约定为准，不把某个游戏或 CAD 的全部行为照搬进来。

## 先区分对象

| 对象 | 责任 |
| --- | --- |
| Item 定义 | 稳定身份、名称、分类、图标；与某个槽位里的数量和位置分开 |
| 文件素材 | 图片等真实文件；不是筛选 Item 的分类目录 |
| 合成面板模板 | 可复用的底图、尺寸、槽位及其输入／输出角色；不携带具体配方材料 |
| 配方 | 使用某种面板布局，规定各槽位的 Item、数量和产出；一个 Item 可有多条配方 |
| 工作区实例 | 底图、槽位、Item 实例、位置和组合关系；拖入配方后默认整体操作 |
| 选择状态 | 选择了什么，以及选择来自单击、多选、CAD 框选还是整体组合 |

“解耦”在此指拆开工作区组合，允许分别操作底图和槽位；不要自行解释为解除数据库引用、克隆整份资源或进入嵌套编辑模式。

## 布局与信息密度

工程界面以工作区为主体，字号、行高、按钮、间距紧凑统一；避免大标题、大卡片和展示网页式留白。

典型分区：左上 Item 目录树，下方一行最近拖出的 Item 图标；左下独立文件素材树；合成面板模板另有面板；右上属性，右下配方。目录用展开三角、缩进和“图标＋名称”列表行，同时保留多个展开分支。不要把目录层级改成分类跳转页或筛选按钮。

界面命名来自对象含义：面板布局不是配方，文件素材不是模板。更名需求若暴露出数据关系不对，先纠正关系，不只替换标签。只调整本次指定区域，不顺带重做整套布局。

## Item 操作与工作区操作分开

- 任意位置单击 Item，统一选择其定义：右上显示 Item 属性，右下显示其配方。目录、最近栏、槽位、工作区、配方预览都走同一入口；不要误显示成槽位属性。
- 超过小幅移动阈值才开始拖动。鼠标带着物品图标和数量，不是物品名称标签；原实例暂时隐藏，目标槽位高亮。
- 从库和最近栏拖出是复制；从工作区拿取是移动。放到占用槽位时明确交换规则；取消、Esc、丢到工作区外还原原物品。完成放置前不要丢失源状态。
- 拖 Item 是拿取物品；拖底图或组边界才移动整套配方。不要让 Item 自动充当组拖动把手。已组合实例仍可拿取内部 Item。
- 最近栏只记录实际拖放使用，去重并把最近项前置；不把单击查看或取消计入。
- 底图、槽点与 Item 共用世界坐标；鼠标坐标经平移、缩放的逆变换定位。网格按缩放级别换档，保持适当疏密且与世界原点对齐。

## CAD 选择与上下文菜单

本基线使用左键空白平移、右键拖动框选、滚轮围绕鼠标缩放。右键单击与拖动必须区分，框选松开后不弹菜单。

- 左向右：蓝色实线框，仅完整包含的对象入选。
- 右向左：绿色虚线框，与选框相交的对象也入选。
- 已组合配方先作为整体计算包围盒，再判断包含或相交；不能先选内部槽位再扩大到整组，否则完整包含规则失效。
- 框选后可整体移动；记录选择来源，不能只用 `selection.size > 1` 判断是否允许组合。

右键按命中对象及状态生成菜单，不复用一份包含所有命令的大菜单：

| 上下文 | 本基线中的操作 |
| --- | --- |
| Item 目录 | 在当前路径新建 Item、子目录；空目录可见且可保存 |
| 目录中的 Item | 绑定图标；不在工作区、最近栏、属性区复制该入口 |
| 槽位 | 输入槽只显示“设为输出”，输出槽只显示“设为输入” |
| 产出 Item | 保存所属配方 |
| 已组合配方的底图 | 解耦该配方 |
| 右键框选得到的集合 | 组合为模板、组合为配方；普通选中或全选不自动获得组合操作 |
| 文件素材区 | 文件导入等素材操作，不混入 Item 或配方命令 |

## 面板、配方与校验

自定义面板可以是任意底图和任意槽位布局，默认九宫格只是预置。槽点支持横纵对齐、辅助线和精确坐标；图像支持拖拽缩放、宽高及比例锁定。

配方预览将面板和材料组合展示；产出 Item 可以放在标题旁，不强制画箭头或把产出画入底图。同一 Item 的多配方提供序号和前后切换。

组合为配方前检查有效输出；缺少输出槽或输出 Item 时明确弹窗拦截。保存模板不要求填写产出 Item。槽位外游离 Item 需警告，说明继续后是否仅作为展示对象保留。删除当前配方先确认，取消不修改；删除配方不顺带删除 Item、模板或工作区实例。

## 实现与验证

- 本地 API、自动保存、多客户端或 AI 同步：先读 [状态与 API](references/state-and-api.md)。
- MC 源码物品身份、图标与 `.png.mcmeta` 动画：按需读 [Minecraft 物品](references/minecraft-items.md)。
- 实际操作要覆盖：点击与拖动、源槽到目标槽、交换与取消、缩放后放置、双向框选及整体边界、菜单出现条件、确认与取消、同一 Item 多配方。
- 验证“物品跟随鼠标、源位置隐藏”等中间态，不能只凭拖放结束后的截图宣称手感完成。
- 测试页面、数据和服务与用户当前工程分开；不强刷或覆盖仍在使用的页面，不把样例、截图、个人路径或整个 Demo 复制进 Skill。
